# 0.10.0 (2026-11-23)

## Highlights

- **Async storage.** With the new `async` feature, every OpenMLS function that reads or writes storage is an `async fn`, and the storage traits return `Send` futures. The sync API stays the default. One crate in the build that enables `async` switches the whole build.
- **Subgroup branching and reinitialization.** Groups can branch into subgroups (RFC 9420 §11.3) and be reinitialized with new parameters (RFC 9420 §11.2).
- **Leaf node lifetime policies.** Message processing, joining and key package validation can check lifetimes against a time the caller passes.
- **Updated PQ ciphersuites.** The `draft-ietf-mls-pq-ciphersuites` ciphersuites follow the updated drafts and `draft-ietf-hpke-pq`. They don't interoperate with 0.9.x.
- **Security fixes.** Includes the fixes for GHSA-gc79-23g3-8g52, GHSA-p276-g3f3-wwgh and GHSA-94v4-rg25-x625.
- **MSRV raised to Rust 1.94.**

## Added

- [#1923](https://github.com/openmls/openmls/pull/1923): Async mode for the storage API (`async` feature).
- [#1913](https://github.com/openmls/openmls/pull/1913), [#2231](https://github.com/openmls/openmls/pull/2231): Subgroup branching (`MlsGroup::branch_info`, `BranchGroupBuilder`, `StagedWelcome::build_from_branch`).
- [#2231](https://github.com/openmls/openmls/pull/2231): Group reinitialization (`MlsGroup::propose_reinit`, `ExternalProposal::new_reinit`, `ReInitGroupBuilder`, `StagedWelcome::build_from_reinit`).
- [#2127](https://github.com/openmls/openmls/pull/2127): `ExternalProposal::new_pre_shared_key`, plus `PreSharedKey` proposals from external senders are now accepted.
- [#2257](https://github.com/openmls/openmls/pull/2257): `LeafNodeLifetimePolicy::VerifyAt` and `*_with_lifetime_policy` variants of message processing and key package validation.
- [#2167](https://github.com/openmls/openmls/pull/2167): `PublicGroup::validate_key_package_for_add`, to check a candidate before building a commit.
- [#2277](https://github.com/openmls/openmls/pull/2277): `ExternalCommitBuilder::verify_group`, to verify the group before building an external commit.
- [#2158](https://github.com/openmls/openmls/pull/2158): `ExternalCommitBuilder::add_proposal(s)` and AppEphemeral proposals in external commits.
- [#2142](https://github.com/openmls/openmls/pull/2142): `Welcome::resolve_own_key_material`.
- [#2175](https://github.com/openmls/openmls/pull/2175): `CommitBuilder::with_aad`.
- [#2184](https://github.com/openmls/openmls/pull/2184), [#2262](https://github.com/openmls/openmls/pull/2262), [#2275](https://github.com/openmls/openmls/pull/2275), [#2127](https://github.com/openmls/openmls/pull/2127): Getters `PreSharedKeyProposal::psk`, `TreeSync::leaf`, `GroupInfo::signer` and `RatchetTreeIn::full_leaves`.

## Changed

- [#2202](https://github.com/openmls/openmls/pull/2202): Secret export functions return `ExportedSecret<T>` instead of `Vec<u8>`.
- [#2205](https://github.com/openmls/openmls/pull/2205): `Capabilities` have no hardcoded defaults, and leaf construction validates them under a `CapabilitiesPolicy`.
- [#2170](https://github.com/openmls/openmls/pull/2170), [#2261](https://github.com/openmls/openmls/pull/2261): PQ ciphersuites follow the updated drafts. Groups on ML-KEM or X-Wing ciphersuites don't interoperate with 0.9.x.
- [#2133](https://github.com/openmls/openmls/pull/2133): `mark_as_last_resort` uses the draft-10 `last_resort_key_package` component (`extensions-draft` feature).
- [GHSA-gc79-23g3-8g52](https://github.com/openmls/openmls/security/advisories/GHSA-gc79-23g3-8g52): `ExtensionValidator` is sealed and `validate_extension_type` takes a different argument type.
- [#2234](https://github.com/openmls/openmls/pull/2234): MSRV raised to Rust 1.94.
- Removed the `js-test` feature. The `js` feature is enough to run the tests on `wasm32-unknown-unknown`.

## Fixed

- [GHSA-p276-g3f3-wwgh](https://github.com/openmls/openmls/security/advisories/GHSA-p276-g3f3-wwgh): Rejected private messages no longer advance the sender ratchet.
- [GHSA-94v4-rg25-x625](https://github.com/openmls/openmls/security/advisories/GHSA-94v4-rg25-x625): Removed leaves no longer reappear after an external commit truncates and regrows the tree.
- [GHSA-gc79-23g3-8g52](https://github.com/openmls/openmls/security/advisories/GHSA-gc79-23g3-8g52): Deeply nested invalid extensions no longer cause unbounded recursion.
- [#2207](https://github.com/openmls/openmls/pull/2207): Commits are checked for signature keys that another member already uses.
- [#2197](https://github.com/openmls/openmls/pull/2197): Reducing the past epoch deletion policy keeps the newest epochs.
- [#2289](https://github.com/openmls/openmls/pull/2289): Values that would decode as a different variant are rejected on encoding.
- [#2247](https://github.com/openmls/openmls/pull/2247): Commits list their proposals in a deterministic order.
- Several fixes to GREASE handling and the `extensions-draft` AppDataUpdate rules. See the changelog.
